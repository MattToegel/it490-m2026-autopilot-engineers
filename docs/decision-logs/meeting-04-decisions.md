## Decision D-018 - Select AeroDataBox as the Primary Flight Data API

## Date:

June 14, 2026

## Status:

Accepted

## Decision:

The team selected AeroDataBox as one of the primary external APIs for OnTheRadar. AeroDataBox will be used to provide flight-related information for the application.

## Rationale:

The team reviewed the researched API options and determined that AeroDataBox best supports the flight-tracking portion of the project. Its available flight information aligns with the project’s need to provide users with flight-related data.

## Consequences:

The API Worker and other components that require external flight information will be designed around AeroDataBox. The team must test the API, determine the required endpoints and request parameters, and integrate returned flight data into the project architecture.

## Related Vote:

Accepted by all five team members during Group Meeting 4 after reviewing the team’s API research.

## Decision D-019 - Select Google Places API for Airport Location Features

## Date:

June 14, 2026

## Status:

Accepted

## Decision:

The team selected Google Places API as an external API for supporting location-based airport features within OnTheRadar.

## Rationale:

Google Places API can provide location information that may support airport-related features and complement the flight data obtained through AeroDataBox.
